# Ethernet Communication Investigation and Traffic Analysis Using Linux

## Overview

An individual honours course project investigating Ethernet communication,
network addressing, TCP/IP protocols, and packet traffic using Linux
networking tools and Wireshark.

## Objectives

- Understand Ethernet frame structure and MAC addressing.
- Investigate IPv4 addressing and routing.
- Analyse ARP, ICMP, TCP, and UDP traffic.
- Practise Linux network diagnostics.
- Capture and interpret packets using Wireshark.
- Document experimental findings and observations.
